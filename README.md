# Nexora Health — Real-World Static Version

A privacy-first personal health organizer 

Features:
- Dashboard
- Medication tracker
- Appointments
- Symptom journal
- Vitals log
- JSON export/import backup
- Responsive mobile UI
- Browser-only storage

Important: this is a personal health organizer, not a diagnostic or emergency-care service. Data is stored in the user's browser. For clinical/production use, add authentication, encrypted server storage, audit logs, consent/privacy controls, backups, and appropriate legal/regulatory review.

Deployment: upload the `public` folder to any static hosting provider such as GitHub Pages, Netlify, Cloudflare Pages, or similar.
